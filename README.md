## 🚀 About

**Jeevika Map** is a digital livelihood discovery and mapping platform designed to help people identify suitable livelihood pathways based on their:

- 🎓 Education
- 🛠️ Existing skills
- 💼 Work experience
- 📍 Location
- 💰 Financial constraints
- 🎯 Career & income aspirations
- 🚜 Employment or self-employment preferences

Instead of making users search through multiple sources, Jeevika Map brings the journey together into a single guided experience.

> **From "Which scheme is for me?" to "What livelihood pathway is right for me?"**
